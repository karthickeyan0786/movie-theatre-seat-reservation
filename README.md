# Movie Theatre Seat Reservation

A front-end movie ticket booking website with a browsing gallery, blog page, contact page, sign-up, and a seat/ticket booking flow.

## Pages
- `index.html` — home page
- `movie-and-bookTicket.html` — movie listing and seat booking
- `Blogs.html` — blog page
- `contact.html` — contact page
- `Signup.html` — sign-up page

## Structure
- `CSS files/` — stylesheets
- `photos/` — images and assets

## Usage
Open `index.html` in a browser to view the site. No build step is required — this is a static HTML/CSS site.
